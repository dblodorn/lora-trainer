# Hide/Unhide LoRAs Plan

**Goal:** Allow users to hide their own LoRAs from the gallery. Hidden loras are filtered out of the public list but still visible to the owner.

## Changes

### 1. Schema — add `hidden` field to `LoraTrainingDoc`
- Add `hidden: boolean` to the interface in `src/server/api/db.ts` (defaults to `false`)
- No migration needed — MongoDB will just have `hidden` missing on existing docs, handled by `?? false`

### 2. API — add `hide`/`unhide` procedures to `loraRouter` in `src/server/api/features/lora.ts`
- `hide: protectedProcedure` — takes `id: string`, checks `walletAddress` match, sets `hidden: true`
- `unhide: protectedProcedure` — same pattern, sets `hidden: false`
- Update `list` query — filter `{ $or: [ { hidden: { $ne: true } }, { walletAddress: currentUser } ] }` so own loras always show
- Update `getById` — no change needed (direct access by ID)

### 3. UI — add hide button to `LoraRow` in `src/components/LoraRow.tsx`
- Needs `walletAddress` prop to compare with current user
- Needs `hidden` prop to show current state
- If current user's wallet matches the lora's wallet, show a small ghost button with an Eye / EyeOff icon from lucide
- Pass `walletAddress` and `hidden` through `LoraGallery` → `LoraRow`

### 4. LoraGallery — pass auth state through
- `LoraGallery` needs to know the current user's wallet address
- Use `authClient.useSession()` from `@/lib/auth-client` to get the current session
- Pass `walletAddress` and `hidden` to each `LoraRow`

## Files
- Modify: `src/server/api/db.ts` (add `hidden` field)
- Modify: `src/server/api/features/lora.ts` (add hide/unhide, update list filter)
- Modify: `src/components/LoraGallery.tsx` (pass wallet/hidden to LoraRow)
- Modify: `src/components/LoraRow.tsx` (add hide button, conditional rendering)

## Flow
1. Owner visits /loras page
2. Each of their loras shows an Eye icon button
3. Clicking it hides the lora (EyeOff icon) — calls `hide` mutation
4. Hidden loras are filtered out for other users via the `list` query
5. Owner can unhide by clicking the EyeOff button
