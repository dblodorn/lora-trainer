# MongoDB Migration Plan

> **For Hermes:** Use subagent-driven-development skill to implement this plan task-by-task.

**Goal:** Replace Turso (libsql/Kysely) with MongoDB as the database for the lora-trainer app. This is a standalone migration — no multi-LoRA or other feature changes. Production app stays on Turso until this branch is merged.

**Architecture:** Replace `kysely` + `@libsql/kysely-libsql` with the `mongodb` npm package. Rewrite `db.ts` as a MongoDB connection module. Rewrite all DB calls in `generate.ts`, `lora.ts`, `fal.ts`, and `slideshow.ts` to use the Mongo driver. Collections mirror the existing tables. Mongo's flexible document model means `image_urls` (currently JSON-encoded string) becomes a native array, and future multi-LoRA can just store an array — no junction table needed.

**Constraints:**
- Must not affect production until merged
- Must not affect any other project/auto DB (separate MongoDB Atlas cluster/URI)
- All existing data must be migratable (see migration script task)

**Tech Stack:** `mongodb` npm package, MongoDB Atlas (free tier), Next.js 16, tRPC 11

### Task 2: Rewrite db.ts — MongoDB connection + collection access

**Objective:** Replace Kysely connection + table interfaces + ensure* functions with a Mongo connection singleton.

**Files:**
- Rewrite: `src/server/api/db.ts`

**Step 1: Rewrite the file**

```typescript
import { MongoClient, Db } from "mongodb";
import { config } from "dotenv";

config({ path: ".env.local" });
config();

let _client: MongoClient | null = null;
let _db: Db | null = null;

export async function getDb(): Promise<Db> {
  if (_db) return _db;

  const uri = process.env.MONGODB_URI;
  if (!uri) {
    throw new Error("MONGODB_URI is not configured. Set it in .env to use database features.");
  }

  _client = new MongoClient(uri);
  await _client.connect();
  _db = _client.db();

  // Ensure indexes
  await ensureIndexes(_db);

  return _db;
}

async function ensureIndexes(db: Db): Promise<void> {
  // lora_trainings indexes
  const loraCol = db.collection("lora_trainings");
  await loraCol.createIndex({ requestId: 1 }, { unique: true });
  await loraCol.createIndex({ status: 1 });
  await loraCol.createIndex({ createdAt: -1 });

  // generated_images indexes
  const imgCol = db.collection("generated_images");
  await imgCol.createIndex({ loraTrainingId: 1 });
  await imgCol.createIndex({ walletAddress: 1 });
  await imgCol.createIndex({ createdAt: -1 });
}
```

### Task 4: Rewrite lora.ts — createPendingLora + loraRouter

**Objective:** Convert all Kysely calls to MongoDB.

**Files:**
- Rewrite: `src/server/api/features/lora.ts`

**Changes:**

1. `createPendingLora`: `db.insertInto("lora_trainings").values(...)` → `db.collection("lora_trainings").insertOne(...)`. Store `imageUrls` as a native array (no `JSON.stringify`).

2. `complete` mutation: `db.selectFrom("lora_trainings").select(...).where("request_id", "=")` → `db.collection("lora_trainings").findOne({ requestId: input.requestId })`. `db.updateTable("lora_trainings").set(...)` → `db.collection("lora_trainings").updateOne({ _id: existing._id }, { $set: { ... } })`.

3. `getById` query: `selectFrom → findOne({ _id: input.id })`. `JSON.parse(row.image_urls)` → just `row.imageUrls` (native array).

4. `list` query: `selectFrom(...).where("status", "=", "completed").orderBy("created_at", "desc")` → `find({ status: "completed" }).sort({ createdAt: -1 }).toArray()`.

**Step 1: Rewrite the file**

See code patterns above. Key transformations:
- `db.selectFrom("lora_trainings").select([...]).where("id", "=", id).executeTakeFirst()` → `await db.collection("lora_trainings").findOne({ _id: id })`
- `db.insertInto("lora_trainings").values({...}).execute()` → `await db.collection("lora_trainings").insertOne({...})`
- `db.updateTable("lora_trainings").set({...}).where("id", "=", id).execute()` → `await db.collection("lora_trainings").updateOne({ _id: id }, { $set: {...} })`
- `db.selectFrom(...).where("status", "=", "completed").orderBy("created_at", "desc").execute()` → `await db.collection("lora_trainings").find({ status: "completed" }).sort({ createdAt: -1 }).toArray()`
- `JSON.parse(row.image_urls)` → `row.imageUrls` (already an array)
- `JSON.stringify(params.imageUrls)` → just `params.imageUrls` (native array)

Note: `_id` in Mongo is the document's primary key. We'll use the same `generateId()` hex string as `_id`.

**Step 2: Update imports**

Replace `import { getDb, ensureLoraTable } from "../db"` with `import { getDb } from "../db"`. Remove all `await ensureLoraTable()` calls (Mongo creates collections on first insert).

Make `getDb()` async — all callers must `await getDb()`.

### Task 6: Rewrite slideshow.ts — slideshowRouter

**Objective:** Convert the randomImages query to MongoDB.

**Files:**
- Rewrite: `src/server/api/features/slideshow.ts`

**Changes:**

1. Random generated images: `db.selectFrom("generated_images").select(["image_url"]).orderBy(db.fn("RANDOM", [])).limit(count)` → MongoDB aggregation pipeline with `$sample`:
   ```
   db.collection("generated_images").aggregate([{ $sample: { size: count } }, { $project: { imageUrl: 1, _id: 0 } }]).toArray()
   ```

2. Random training images: same pattern with `lora_trainings` collection, filter `{ status: "completed" }`, then extract from `imageUrls` array (no more `JSON.parse`).

**Step 1: Rewrite the file**

```typescript
import { z } from "zod";
import { publicProcedure, router } from "../trpc";
import { getDb } from "../db";

function shuffle<T>(arr: T[]): T[] { ... }

export const slideshowRouter = router({
  randomImages: publicProcedure
    .input(z.object({ count: z.number().int().min(1).max(20).default(10) }).default({}))
    .query(async ({ input }) => {
      const db = await getDb();

      // 1. Random generated images
      const genDocs = await db.collection("generated_images")
        .aggregate([
          { $sample: { size: input.count } },
          { $project: { imageUrl: 1, _id: 0 } },
        ])
        .toArray();
      const genUrls = genDocs.map(d => d.imageUrl);

      // 2. Random training rows
      const trainingDocs = await db.collection("lora_trainings")
        .aggregate([
          { $match: { status: "completed" } },
          { $sample: { size: 5 } },
          { $project: { imageUrls: 1, _id: 0 } },
        ])
        .toArray();

      const trainingUrls: string[] = [];
      for (const doc of trainingDocs) {
        if (Array.isArray(doc.imageUrls)) {
          trainingUrls.push(...doc.imageUrls);
        }
      }

      // 3. Combine, deduplicate, shuffle
      const allUrls = [...new Set([...genUrls, ...trainingUrls])];
      shuffle(allUrls);
      return { urls: allUrls.slice(0, input.count) };
    }),
});
```

### Task 8: Create data migration script

**Objective:** Script to migrate existing data from Turso to MongoDB. Run manually before deploying the merged branch.

**Files:**
- Create: `scripts/migrate-turso-to-mongo.ts`

**Step 1: Create the script**

```typescript
import { Kysely, sql } from "kysely";
import { LibsqlDialect } from "@libsql/kysely-libsql";
import { MongoClient } from "mongodb";
import { config } from "dotenv";

config({ path: ".env.local" });
config();

async function migrate() {
  // Source: Turso
  const tursoDb = new Kysely({
    dialect: new LibsqlDialect({
      url: process.env.TURSO_DATABASE_URL!,
      authToken: process.env.TURSO_AUTH_TOKEN,
    }),
  });

  // Destination: MongoDB
  const mongoClient = new MongoClient(process.env.MONGODB_URI!);
  await mongoClient.connect();
  const mongoDb = mongoClient.db();

  // Migrate lora_trainings
  const loraRows = await tursoDb.selectFrom("lora_trainings").selectAll().execute();
  console.log(`Migrating ${loraRows.length} lora_trainings...`);
  for (const row of loraRows) {
    await mongoDb.collection("lora_trainings").insertOne({
      _id: row.id,
      requestId: row.request_id,
      walletAddress: row.wallet_address,
      triggerWord: row.trigger_word,
      steps: row.steps,
      imageUrls: JSON.parse(row.image_urls),
      loraWeightsUrl: row.lora_weights_url,
      arenaChannelUrl: row.arena_channel_url,
      arenaChannelTitle: row.arena_channel_title,
      status: row.status,
      createdAt: row.created_at,
    });
  }

  // Migrate generated_images
  const imgRows = await tursoDb.selectFrom("generated_images").selectAll().execute();
  console.log(`Migrating ${imgRows.length} generated_images...`);
  for (const row of imgRows) {
    await mongoDb.collection("generated_images").insertOne({
      _id: row.id,
      loraTrainingId: row.lora_training_id,
      walletAddress: row.wallet_address,
      prompt: row.prompt,
      imageUrl: row.image_url,
      imageWidth: row.image_width,
      imageHeight: row.image_height,
      seed: row.seed,
      loraScaleValue: row.lora_scale_value,
      loraScaleName: row.lora_scale_name,
      genWidth: row.gen_width,
      genHeight: row.gen_height,
      createdAt: row.created_at,
    });
  }

  console.log("Migration complete!");
  await mongoClient.close();
  await tursoDb.destroy();
}

migrate().catch(console.error);
```

Note: The script temporarily installs `kysely` + `@libsql/kysely-libsql` as devDeps for the migration only, or reads from Turso directly via the libsql client. Since we're removing those deps from the project, the script should be standalone with its own package.json or use `npx tsx` with inline deps.

**Alternative approach:** Run the script before uninstalling kysely, or keep kysely as a devDep for the migration script only.

## Key Transformations

| Kysely pattern | MongoDB equivalent |
|---|---|
| `db.selectFrom("table").select([...]).where("field", "=", val).executeTakeFirst()` | `await db.collection("table").findOne({ field: val })` |
| `db.selectFrom("table").select([...]).where(...).orderBy("col", "desc").execute()` | `await db.collection("table").find({...}).sort({ col: -1 }).toArray()` |
| `db.insertInto("table").values({...}).execute()` | `await db.collection("table").insertOne({...})` |
| `db.updateTable("table").set({...}).where("id", "=", id).execute()` | `await db.collection("table").updateOne({ _id: id }, { $set: {...} })` |
| `db.fn.countAll()` | `await db.collection("table").countDocuments({...})` |
| `db.fn("RANDOM", [])` + `.limit(n)` | `db.collection("table").aggregate([{ $sample: { size: n } }])` |
| `JSON.parse(row.image_urls)` | `row.imageUrls` (native array) |
| `JSON.stringify(arr)` | just `arr` (native array) |
| snake_case column names | camelCase field names (Mongo convention) |
| `ensureLoraTable()` / `ensureGeneratedImagesTable()` | removed (Mongo creates collections on first insert, indexes created in getDb()) |
