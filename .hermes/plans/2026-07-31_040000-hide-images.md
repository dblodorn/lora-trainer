# Hide Individual Generated Images Plan

**Goal:** Allow users to hide individual generated images, with an Eye toggle in the image tile caption area and a dedicated `/hidden-generations` route to view all hidden images.

## Changes

### 1. Schema — add `hidden` to `GeneratedImageDoc`
- Add `hidden: boolean` to `src/server/api/db.ts`
- Add index: `{ walletAddress: 1, hidden: 1 }` for efficient queries

### 2. API — add hide/unhide/listHidden to generate router
In `src/server/api/features/generate.ts`:
- `hideImage: protectedProcedure` — takes `id`, checks `walletAddress` match, sets `hidden: true`
- `unhideImage: protectedProcedure` — same pattern, sets `hidden: false`
- `listHiddenImages: publicProcedure` — returns images where `hidden: true`, sorted by `createdAt: -1`

### 3. GeneratedImageGrid — add Eye toggle in caption area
- Add optional `currentWallet` and `onHide` props
- In the caption area (right side of the prompt/date row), render a small Eye/EyeOff ghost button
- Only shows when `currentWallet` matches the image's wallet
- The toggle calls `hideImage`/`unhideImage` mutations and invalidates the list

### 4. HiddenGenerations page
- Create `src/pages/hidden-generations.tsx` — same layout as `/hidden`
- Uses `trpc.generate.listHiddenImages.useQuery()`
- Renders a `GeneratedImageGrid` with all hidden images
- Same full-height centered loader pattern

### Files
- Modify: `src/server/api/db.ts` (add `hidden` to GeneratedImageDoc, add index)
- Modify: `src/server/api/features/generate.ts` (add hide/unhide/listHidden procedures)
- Modify: `src/components/GeneratedImageGrid.tsx` (add Eye toggle in caption)
- Create: `src/pages/hidden-generations.tsx` (hidden images route)

### Flow
1. Owner visits lora detail page → sees generated images grid
2. Each image they own shows an Eye icon in the caption area
3. Clicking it hides the image → EyeOff icon
4. Image is filtered out of future `listByLora` queries
5. `/hidden-generations` shows all hidden images with an unhide option
